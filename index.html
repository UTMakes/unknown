Getting Started

  • Start with your Router - it's your network core
  • Buy nodes from the toolbar at the bottom (5 tabs now!)
  • Connect nodes by dragging between green and blue ports
  • Nodes must be connected to the Router to work!

Quick Tips

  • Downloaders (blue) collect files/images/videos/audio
  • Uploaders (teal) sell data for money
  • Labs (purple) convert files to Research Points (RP)
  • Firewalls protect nearby nodes from viruses
  • Overclock doubles speed but generates heat!
  • Coder Nodes (cyan) produce code bits for drivers
  • Check the Advanced tab for powerful late-game nodes

Controls

  • Scroll or +/- to zoom in/out
  • 0 to reset zoom to 100%
  • Drag empty space to pan the view
  • Right-click a node to open upgrade/delete menu
  • Drag from green port to blue port to connect nodes ($10 per cable)
  • X to toggle cable delete mode (click cables to delete, $5 refund)

NEW: Coding System

  • Coder Nodes generate code bits over time
  • Convert 100 code bits → 1 Optimization Code
  • Use optimization code to create Drivers
  • Drivers provide permanent global bonuses!
