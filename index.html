Help & Instructions

Network Hierarchy (Flow)

Network layout is a strategic puzzle! Nodes now follow a strict 4-tier hierarchy. Data can ONLY flow from a lower tier to a higher tier.

Tier 1: Sources (Miners, File DLs, etc.)
Tier 2: Bridge/Utility (Cache, Balancer, etc.)
Tier 3: Processor/Storage (Uploaders, Labs, Racks)
Tier 4: Hubs (Routers)

You cannot connect a Tier 4 Router to a Tier 1 Miner!
